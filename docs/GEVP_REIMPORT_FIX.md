# Исправление GEVP после реимпорта

## Проблема

После удаления `.godot/imported/` (реимпорт ассетов) машина с GEVP физикой застревает в земле. Колёса не работают, машина проваливается сквозь землю.

## Симптомы

- Машина падает и застревает в земле
- Колёса не касаются поверхности / не работают
- Происходит только после реимпорта (удаления `.godot/imported/`)

## Решение

**Открыть редактор Godot перед запуском игры:**

```bash
# 1. Сначала открыть редактор
/Applications/Godot.app/Contents/MacOS/Godot --path . --editor

# 2. Подождать пока редактор полностью загрузится

# 3. Запустить игру из редактора (F5) или закрыть редактор и запустить игру
/Applications/Godot.app/Contents/MacOS/Godot --path .
```

## Почему это работает

GEVP использует RayCast3D для колёс и кастомную физику. После реимпорта некоторые ресурсы (ArrayMesh колёс, скрипты wheel.gd) требуют переинициализации, которая корректно происходит только при открытии редактора.

## Команда для реимпорта (правильная последовательность)

```bash
# Удалить кэш
rm -rf .godot/imported

# Открыть редактор (дождаться полной загрузки!)
/Applications/Godot.app/Contents/MacOS/Godot --path . --editor

# После этого можно запускать игру
```
