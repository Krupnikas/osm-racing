# Визуальные барьеры гонки (Race Barriers)

Полупрозрачные стенки по краям маршрута гонки с указателями направления движения.

## Назначение

- Визуальный ориентир границ трассы
- Стрелки показывают направление движения
- Без коллизии — машина проезжает сквозь

## Файлы

| Файл | Описание |
|------|----------|
| [race/race_barriers.gd](../race/race_barriers.gd) | Основной скрипт барьеров |
| [race/race_manager.gd](../race/race_manager.gd) | Создание/удаление барьеров |

## Параметры

| Константа | Значение | Описание |
|-----------|----------|----------|
| `BARRIER_OFFSET` | 7.0 м | Расстояние от центра маршрута |
| `BARRIER_HEIGHT` | 2.5 м | Высота стенки |
| `BARRIER_THICKNESS` | 0.1 м | Толщина стенки |
| `ARROW_SPACING` | 30.0 м | Интервал между стрелками |
| `ARROW_SIZE` | 1.5 м | Размер стрелки |

## Цвета

### День
- **Барьеры**: 15% чёрный `Color(0.0, 0.0, 0.0, 0.15)`

### Ночь
- **Барьеры**: 1% белый `Color(1.0, 1.0, 1.0, 0.01)`

### Стрелки
- **Цвет**: 50% красный `Color(1.0, 0.2, 0.2, 0.5)`
- Не меняются день/ночь

## Управление

| Клавиша | Действие |
|---------|----------|
| **G** | Показать/скрыть барьеры (Guide) |

В консоли выводится: `Race barriers: visible` или `Race barriers: hidden`

## Жизненный цикл

1. **Создание**: автоматически при старте гонки (`_create_barriers()`)
2. **Удаление**: при финише или отмене гонки (`_clear_barriers()`)

## Адаптация к освещению

Барьеры автоматически подключаются к `NightModeManager` и меняют цвет при переключении дня/ночи через сигнал `night_mode_changed`.

## Алгоритм построения

Для каждой точки маршрута:

```gdscript
# Усреднённое направление "вперёд"
var forward := (dir_from_prev + dir_to_next).normalized()

# Перпендикуляр (вправо)
var right := forward.cross(Vector3.UP).normalized()

# Смещённые точки для стен
var left_pt := point + (-right * BARRIER_OFFSET)
var right_pt := point + (right * BARRIER_OFFSET)
```

Стрелки размещаются на стенах с шагом `ARROW_SPACING` метров, ориентированы в плоскости стены кончиком по направлению движения.
